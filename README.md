# OSCP Notes & Toolkit
 
Repositorio con mis apuntes, herramientas y recursos de estudio del máster y la preparación de la certificación **OSCP** (Offensive Security Certified Professional).
 
Lo voy actualizando a medida que avanzo en el máster y en la práctica de máquinas, así que iré subiendo cada vez más contenido: nuevas técnicas, cheatsheets, scripts y writeups de las máquinas que vaya resolviendo.
 
## Contenido
 
- **Metodología**: flujo de trabajo desde el reconocimiento hasta la post-explotación
- **Enumeración**: escaneo de puertos, servicios web, SMB, SNMP, DNS, etc.
- **Explotación**: vulnerabilidades comunes, uso de exploits y adaptación de PoCs
- **Escalada de privilegios**: técnicas y checklists para Linux y Windows
- **Active Directory**: enumeración, ataques y movimiento lateral
- **Pivoting y tunneling**: port forwarding, proxychains, chisel, ligolo-ng
- **Scripts y herramientas**: utilidades propias y recopiladas
- **Writeups**: resolución de máquinas de HTB, Proving Grounds y TryHackMe
- **Cheatsheets**: comandos de referencia rápida
